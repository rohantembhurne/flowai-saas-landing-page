# FlowAI — Premium SaaS Landing Page

React + Vite + Tailwind CSS + JavaScript.

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Included
- Responsive sticky navigation
- Hero + product dashboard mockups
- Trusted-by section
- 6 feature cards
- How It Works
- Benefits / metrics
- Product showcase
- Pricing
- Testimonials
- FAQ accordion
- Validated contact form with success state
- Footer with navigation, privacy and terms links
- Accessible labels, buttons and responsive layouts
